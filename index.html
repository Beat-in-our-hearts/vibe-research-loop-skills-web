01install.sh

Install in one prompt

One sentence in Claude Code or Codex installs all seven skills.

02vrl-init-workspace

Set up once per machine

Workspace, Notion project, and tools, ready in one run.

03vrl-propose-ideaYou decide

Turn a hunch into a testable idea

A hypothesis, its evidence, and a staged test. You approve it first.

04vrl-plan-experimentYou decide

Plan before anything runs

Every run, step, and cost, sized to the budget. You approve the plan.

05vrl-run-experiment

Run, and hear back when it matters

Jobs run in tmux and report when there is news.

06vrl-analyze-results

Turn metrics into evidence

Mean ± std, significance, and figures, straight from the metrics files.

07vrl-write-findingYou decide

Record what you verified

A paper-style finding that counts once you confirm it.

08Notion

Many experiments at once

One board, kept current by the agents.

09Review by color

Mark it, and the agent answers

Red is wrong, orange is unclear, purple is not acceptable.

10Remote mode
